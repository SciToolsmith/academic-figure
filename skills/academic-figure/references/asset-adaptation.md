# 案例与模板适配

## 四级复用决策

### Exact

只在观察单位、变量角色、设计关系、不确定性口径和数据规模都匹配时使用。只替换字段映射、数据和少量配置。

### Structural

保留信息架构和编码逻辑，但按数据调整面板数量、方向、分面、坐标尺度、标签策略和输出尺寸。这是最常用的复用级别。

### Style-only

只借用主次层级、色彩角色、字体级别、线宽比例、留白和标注原则。不复制实例数值、标签、基因名、阈值、统计结论和固定行列。

### New

数据契约或证据任务不匹配时从头选图。可用图鉴作视觉参考，但不用其代码或面板逻辑。

## 开放层与图鉴层

- `releaseTier: atlas`：可用缩略图、元数据和通用提示词，但完整实现未必公开。
- `releaseTier: open-template`：可考虑使用经过去案例化的开放模板。
- `openImplementation.python/r`：只有对应值为 `true` 时，才能声称存在该语言的开放实现。

使用开放模板时：

1. 用 `--open-only --language <python|r>` 检索，确认返回了 `templatePath`。
2. 先读模板 `README.md` 的字段契约、统计边界和不适用条件，再读目标语言脚本。
3. 将用户实际字段映射到语义角色；关键映射不清楚时先问，不通过改列名掩盖含义不明。
4. 先用用户数据通过模板校验，再按 `exact` 或 `structural` 层级调整。模板不匹配时退回 `style-only` 或 `new`。

未发布候选、维护者评分和私有源码不是用户面向产品。公开发布注册表及其中已经验证的波次、角色和模板路径可以正常引用；不得泄露未发布材料的路径、文件名或来源。

## 去案例化检查

开放模板必须：

- 不包含原案例文件名、绝对路径、特定基因/疾病/区域名、实例阈值和结论。
- 使用语义角色映射，不强制用户改成固定列名。
- 将阈值、标签数、排序、面板数和尺寸暴露为可调配置。
- 验证必需字段、类型、取值范围和关键关系，绘图前用可读错误停止。
- 演示数据必须独立、明确标注，不将原案例数据伪装成通用模板。
