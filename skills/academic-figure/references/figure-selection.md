# 从研究问题选图

不要把“上传一张图”等同于“找得最像的图”。参考图可以提供面板结构、编码、美学和领域惯例线索；最终选择必须由用户的数据设计决定。

## 选图五步

1. **证据任务**：比较差异、展示分布、估计效应、变量关系、组成/集合、网络/流向、时间过程、空间/层级或高维结构。
2. **观察单位**：一行是个体、样本、时点、特征、区域、节点、边还是集合？
3. **变量结构**：连续/离散/有序，一个/多个响应，长表/矩阵/节点边表/空间表/组成表。
4. **设计约束**：独立还是配对，是否重复测量、层级、删失、空间依赖，是否只有汇总值或模型输出。
5. **证据强度**：是否需要显示原始观测、效应和区间、密度、样本量、模型拟合、连接关系或轨迹。

## 常见方向（不是硬规则）

| 问题 | 优先考虑 | 需警惕 |
|---|---|---|
| 独立组的分布和差异 | 原始点 + 密度/箱线/估计图 | 只用均值柱形隐藏分布 |
| 配对或重复测量 | 连线点图、变化量、轨迹或模型估计 | 将配对数据当独立组 |
| 效应与不确定性 | 森林图、点-区间图、估计图 | 用显著星号替代效应量 |
| 两个连续变量 | 散点 + 合理拟合/不确定性 | 不检查尺度、异方差和群组结构 |
| 多变量矩阵 | 热图、排序矩阵、聚类或降维 | 未说明标准化和距离定义 |
| 组成或份额 | 堆积图、三元图、组成专用表达 | 忽略闭合约束，用面积做精确比较 |
| 集合交集 | UpSet；小集合数时可用 Venn | 集合过多仍强行 Venn |
| 节点、边和转移 | 网络、Sankey/alluvial、弦图 | 边太密或未区分流向与关系 |
| 时间过程 | 轨迹、折线、泳道、面积或事件图 | 忽略个体轨迹和不规则时间间隔 |
| 空间或层级 | 地图、分层树、树图或环形层级 | 将邻接、面积或层级当普通类别 |
