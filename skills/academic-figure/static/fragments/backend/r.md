# R 路线

根据任务选择最少足够的工具：

- 数据：`readr`, `dplyr`, `tidyr`；XLSX 可用 `readxl`。
- 绘图：优先 `ggplot2`；多面板可用 `patchwork`。
- 标签避让：`ggrepel`；热图可选 `ComplexHeatmap`。
- 输出：优先 `svglite`/`cairo_pdf`；高质量位图可用 `ragg`。
- 网络、空间、系统发育和组合图库只在图形契约需要时加载。

脚本要求：

- 将可调参数放在紧凑配置区，将字段映射与绘图实现分开。
- 分离读取/验证、整形、统计处理、绘图和导出。
- 不使用隐式因子顺序或未记录的默认聚合；排序、参考组和缺失值处理应明确。
- 大数据使用后端原生的栅格化、聚合或密度表达，不默默抽样。
- 使用 `ggsave()` 时明确宽高与单位；矢量输出保留文字，位图按最终物理尺寸确定像素。
- 将字体家族和字号层级放入配置。含 CJK 文字时，先精确比对 `systemfonts::system_fonts()$family` 再选择字体；可优先尝试 `Source Han Sans CN`、`Hiragino Sans GB`，不要用会静默返回默认字体的结果证明某字体存在。
- 找不到可覆盖实际标签的 CJK 字体时，清楚说明阻塞或选择已验证备用字体；检查缺字、异常回退、中文与拉丁/数学符号混排和真实字重。
- PDF 优先 `cairo_pdf`，SVG 可用 `svglite`，高质量位图优先 `ragg`。矢量交付后核对字体与 Unicode 映射；需要轮廓版时同时保留可编辑源。

生成后，用 R 实际运行脚本并检查输出。如果缺少 R 或依赖，说明阻塞及安装方式，不用 Python 偷换渲染。
