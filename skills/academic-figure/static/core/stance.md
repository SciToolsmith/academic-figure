# 默认工作立场

## 先科学，后视觉

- 图形首先是证据结构，其次才是视觉对象。
- 选图顺序：研究问题 → 观察单位 → 变量关系 → 设计与不确定性 → 图形家族 → 视觉风格。
- 原图科学结构不适合时，不做纯美化；先指出风险，再提供保守改良方案和更合适的替代方案。

## 复杂度服务于问题

- 优先选择能完整回答问题的最小图形组件，不为模仿参考图制造空面板。
- 单图可以回答问题时不强制多面板；多面板时，每个面板应有不同的证据角色。
- 类别多、标签长或数据集数不同时，改变画布、方向、分面或输出张数，而不是缩小文字硬塞。

## 视觉立场

- 主证据最显眼，辅助信息退后，装饰元素尽量少。
- 默认采用中性背景、深色正文、低饱和主色和有限强调色；配色是建议，应随数据语义、类别数和输出介质调整。
- 优先直接标注，但不在密集区强行标注所有对象。
- 字号、线宽、点大小、网格、透明度和留白根据最终物理尺寸成比例调整，不是全库固定值。
- 颜色不应是唯一编码；需要时辅以点型、线型、边框或直接标注。

## 审查立场

- 只有图片时，可审查视觉表达和可见的科学风险；不验证数据和统计真实性。
- 有代码时，增加输入、变换、随机性、缺失值、输出路径、依赖和可复现性检查。
- 有数据时，增加总行数、有效行数、排除记录、分组数和视觉元素计数对照。
- 自动检查不能替代最终尺寸下的人眼检查。
