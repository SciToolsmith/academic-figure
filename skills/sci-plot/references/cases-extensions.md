# 扩展案例卡

仅在核心案例不能覆盖领域特有的数据结构时加载以下案例。每次任务最多选择一个扩展案例；仍以科学问题和输入契约为准。

## `rf-0054` — 聚类模式、代表特征与富集注释

[预览](../assets/cases/rf-0054.webp)

- **科学问题**：共同变化的特征形成哪些模块，这些模块分别对应哪些功能主题？
- **数据结构**：标准化表达矩阵、样本元数据、已确定的簇分配、代表特征和预计算富集结果。
- **证据角色**：让簇轮廓、热图行块、代表基因和富集注释共享同一模块顺序，形成模式到功能的解释链。
- **禁用条件**：在绘图代码中临时改变聚类或富集结果；样本/特征 ID 无法对齐；用描述性模块暗示机制或因果。
- **已知风险**：标准化、距离、簇数和富集背景集都会改变叙事；复杂布局容易让热图本身失去可读性。
- **目录状态**：审计 `conditional`；实现 `static-reviewed`。修复门槛：把上游分析结果冻结为显式输入，并验证跨面板 ID 和顺序。

## `rf-0063` — 共享患者顺序的临床特征轨道

[预览](../assets/cases/rf-0063.webp)

- **科学问题**：患者层面的定量、分类和结局特征是否形成共现模式或关键亚群？
- **数据结构**：每行一个患者；多个连续/分类字段，可选结局或分组；所有轨道使用同一患者键。
- **证据角色**：将条形、连续色阶和分类色块沿共同患者轴对齐，使跨轨道比较可追踪到同一对象。
- **禁用条件**：各轨道来自无法连接的不同人群；排序变量事后选择却未说明；缺失值被当作生物学类别。
- **已知风险**：按某一结局排序会强化视觉相关；高基数字段和密集患者 ID 不可读；连续色阶可能跨不同单位误比较。
- **目录状态**：审计 `conditional`；实现 `static-reviewed`。修复门槛：声明唯一患者键、排序优先级、缺失编码、单位和轨道方向。

## `rf-0035` — 对象历程与离散事件泳道图

[预览](../assets/cases/rf-0035.webp)

- **科学问题**：每个对象经历了多长时间、哪些事件在何时发生、状态何时改变？
- **数据结构**：对象 ID、观察起止时间、区段状态、事件类型和事件时间；所有时间使用共同起点与单位。
- **证据角色**：以横向区段表达持续时间，以符号表达离散事件，以排序帮助比较历程而不抹掉对象级信息。
- **禁用条件**：事件时间晚于已知随访终点且无解释；时间起点混杂；对象太多导致每行低于可读高度。
- **已知风险**：按结果或持续时间排序会影响叙事；天/月换算可能引入误差；颜色同时承担患者组和状态会混淆。
- **目录状态**：审计 `conditional`；实现 `static-reviewed`。修复门槛：验证事件与随访时间、共同起点、排序规则、单位转换和删失含义。

## `rf-0176` — 预计算低维坐标展示

[预览](../assets/cases/rf-0176.webp)

- **科学问题**：已有低维嵌入中，不同细胞亚型如何分布、分离或形成过渡区域？
- **数据结构**：每行一个细胞/对象；预计算坐标、类别标签、可选样本/批次；保留嵌入参数与来源。
- **证据角色**：将高密度点云、类别编码、直接标签和必要的抽样/栅格化策略组合成可读视图。
- **禁用条件**：只有原始表达矩阵却把本案例当成 UMAP 计算流程；用手工模拟团块冒充真实嵌入；跨数据集直接比较坐标距离。
- **已知风险**：UMAP 全局距离不可直接解释；随机种子、邻居数、批次校正和抽样都会改变几何；类别过多造成颜色拥挤。
- **目录状态**：审计 `conditional`；实现 `static-reviewed`。修复门槛：只消费经过审核的坐标，记录上游方法、参数及抽样/栅格化策略，并限制为描述性解读。

## `rf-0118` — 多阶段流向与带宽语义

[预览](../assets/cases/rf-0118.webp)

- **科学问题**：对象或权重如何在多个阶段、类别或状态之间转换？
- **数据结构**：记录级路径，或带有 `source`、`target`、`stage`、`weight` 的边表；必须定义带宽是对象数还是权重。
- **证据角色**：用节点显示状态，用流带显示相邻阶段转换规模；当两套数据没有共享记录键时，分面而不伪造联合路径。
- **禁用条件**：只有各阶段边际频数却推断个体流向；不同测量单位共用带宽；无共享键的数据被强行串联。
- **已知风险**：节点顺序改变交叉程度和视觉重点；小流带与标签易丢失；汇总权重会隐藏个体异质性。
- **目录状态**：审计 `conditional`；实现 `static-reviewed`。修复门槛：确认共享记录键或分离不兼容流，声明带宽语义，并补审排序稳定性。

## `rf-0159` — 具有空间契约的区域/点位地图

[预览](../assets/cases/rf-0159.webp)

- **科学问题**：区域指标或样本点位是否呈现空间梯度、聚集热点或地区差异？
- **数据结构**：带 CRS 的几何对象，或可地理编码的经纬度/区域键及数值；边界数据需有版本信息。
- **证据角色**：在主地图与局部放大图中一致编码位置和数量，配合比例尺、方向、图例与必要的空间背景。
- **禁用条件**：CRS 未知；行政区键无法可靠匹配；把空间共现解释为因果；气泡半径而非面积与数量成比例。
- **已知风险**：投影造成面积/距离失真；底图版本和边界表达影响含义；点位重叠与地理编码误差会制造热点。
- **目录状态**：审计 `conditional`；实现 `static-reviewed`。修复门槛：记录 CRS、边界来源/版本、地理匹配表、点面积缩放和局部图范围。
