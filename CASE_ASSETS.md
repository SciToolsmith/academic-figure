# Case asset provenance

The preview images under `skills/sci-plot/assets/cases/` are independent,
code-authored reconstructions created by the project owner for the study of
scientific-figure design decisions.

They are not:

- images copied from publisher PDFs or journal websites;
- source code supplied with the referenced papers;
- raw research datasets;
- claims of affiliation with the original authors, Nature, or Springer Nature.

The previews are included as design references. They teach choices such as
panel roles, uncertainty display, paired structure, evidence ordering, and
diagnostic layout. They are not templates whose numbers, labels, or scientific
conclusions should be transplanted into new work.

Some previews retain dataset-scale labels or generic record identifiers so the
scientific-expression problem remains intelligible. These labels must not be
treated as input data, reanalysed, or presented as results generated by this
repository.

No paper-specific raw data or case-generation scripts are distributed in this
release. The repository license governs the included preview files unless an
asset is explicitly marked otherwise in a future release.
